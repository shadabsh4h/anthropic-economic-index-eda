# Anthropic Economic Index — EDA

Exploratory Data Analysis on Anthropic's real-world 
Claude.ai usage dataset (1,636,573 rows × 10 columns).

## Dataset
Source: Hugging Face — Anthropic/EconomicIndex  
Release: June 2026 | License: MIT

## Key Findings
- Education & Learning dominates global Claude usage
- Content Creation & Copywriting highest in Nigeria
- Service and Electrical occupations use Claude 
  almost exclusively for professional work (90-100%)
- onet tasks span all 4 hierarchy levels

## Tools
Python, Pandas, Matplotlib, Seaborn, Jupyter

## Scope
First-phase analysis focused on global-level data
as a structured entry into this multi-dimensional dataset.
